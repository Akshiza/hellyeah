# for-him bouquet site

A single-page pixel-art gift: opens with "I LOVE YOU SM MWAH", shows a different
flower each calendar day (30 total, then loops), and has a "know more about this
flower" button with a short line for each one.

It's pure HTML/CSS/JS (all in index.html) — no build step, no dependencies,
no backend/server needed. See DEPLOY.md for how to put it online.
